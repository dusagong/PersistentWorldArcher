# 궁수 이펙트

원본 투명 PNG를 런타임에 프레임 분할한다. 조작·판정의 최신 기준은 `Scripts/Player/CLASS_SKILLS.md`와 루트 README다.

- `BasicAttackBow.png`: 1254×1254, 2×2. 우클릭 평타마다 60ms 간격 4프레임, 0.18초에 화살 발사, 0.24초에 활 정리.
- 좌클릭 일석이조는 새 `ArcherSpecial.png`의 마법진 9프레임을 5초 동안 반복하며 캐릭터 몸 중심 뒤를 따라간다. 같은 Sorting Layer에서 캐릭터보다 한 단계 뒤에 그려지며 발밑 바닥 효과로 배치하지 않는다. 별도 공격 입력이 없으면 화살을 생성하지 않고, 평타의 활 4프레임·2연사·공격 간격은 유지한다. 메뉴를 열어도 버프 동안 유지하며 종료·직업 변경·사망 시 정리한다.
- `BasicAttackArrow.png`: 1254×1254, 단일 NE 방향 화살. 조준 방향으로 회전·이동하며 실제 충돌 위치에 끝을 고정한다.
- `SkillOneVolley.png`: 1026×684, 3×2. 오지마의 분홍 화살 연출은 80ms 간격 6프레임이다. 범위선은 표시하지 않는다. 실제 효과는 전방 90도 범위 피해·넉백이며 보스 패턴 중 넉백은 제외한다.
- `SkillTwoArrowRain.png`: 1026×1026, 3×3. Q/E에 화살 비를 장착하고 키를 누르면 범위가 보이며, 놓으면 80ms 간격 9프레임을 재생한다. 첫 착탄인 프레임3(0.24초)에 타원 안의 적을 한 번 공격한다.
- `SkillThreeCast.png`: 1254×1254, 3×3. 저격 차징 완료/키 해제 후 80ms 간격 9프레임 활 연출. 프레임7(0.56초)에 차징 피해·사거리를 적용한 화살 발사.
- 저격 차징 중에는 마우스로 조준 방향을 바꿀 수 있다. 키를 놓거나 최대 차징에 도달한 순간의 방향을 발사 연출·화살에 함께 적용하고, 발사 준비가 시작된 후에는 그 방향을 유지한다.
- `SkillThreeFlight.png`: 1026×1026, 3×3. 저격 화살의 9프레임 비행 반복, 충돌·사거리 종료 시 정리.

왼쪽 방향 및 대각선 원본은 조준 방향으로 회전·반전한다. 저격 시트의 초록 가이드는 각 셀 가장자리 2픽셀 제외로 제거한다. 집중 상태의 피해 1.5배 보너스는 이전 프로토타입에서 제거했고, 기획서의 일석이조(공속 증가+평타 2연사)로 교체했다.

전사·힐러의 새 시트는 `ClassSheetEffect`로 연결했다. WarriorWhirlwind/Combo/Charge/Release/Parry, HealerBolt/HealingZone/Cleanse/Judgment/Revive의 원본 프레임을 80ms 간격으로 재생한다. 힐링 존·레이저·패링은 실제 지속 시간 동안 반복하고, 원형베기·연속베기·정화·부활은 한 번 재생 후 정리한다. 전체 원본 경로와 격자는 `Docs/CHARACTER_ASSETS.md`를 참고한다.
