# 직업 스킬·사망 기능 팀 통합 안내

기준: 팀 Google 기획서, 2026-10-29 확인. 특수 스킬은 장착·해제만 불가하며 좌클릭으로 사용한다. 사용자 확인 사항: 일반 지역 사망 시 10초 뒤 마을 귀환, 보스전 사망 시 전투 종료까지 잔류.

## 구성과 조작

기존 씬 참조를 보존하려고 `ArcherController`의 이름·GUID를 유지했다. 실제 역할은 세 직업 공통 이동·입력·사망 처리다. Awake에서 `SkillLoadout`, `PlayerSkills`, `CombatStatus`를 연결하므로 기존 Town/Field/BossArena에서 바로 작동한다.

- 우클릭 평타, 좌클릭 직업 특수, Q/E 일반 장착 스킬, Shift 보스 스킬, Space 회피, ESC 메뉴.
- 각 직업의 일반 스킬 세 개 중 두 개만 장착. 같은 스킬 중복·다른 직업 스킬·보스 슬롯에 일반 스킬 장착을 거부한다.
- ESC → 직업에서 마을 직업 변경. 직업별 장착은 세션 내 씬 이동 시 유지된다.
- 쿨타임은 스킬 기준으로 유지되므로 해제·재장착·씬 이동으로 초기화되지 않는다.
- 스킬 상태의 게임 종료 후 저장, MP, 레벨, 네트워크는 아직 연결하지 않았다. cy 통합으로 장비·인벤토리·무기 강화의 로컬 저장 및 공격력·방어력·세트 효과 연결을 추가했다. 수치는 모두 프로토타입 값이다.

## 직업 동작

| 직업 | 평타 | 일반 스킬 | 고정 특수 |
|---|---|---|---|
| 궁수 | 화살, 활 4프레임 | 오지마: 90도·넉백 / 화살 비: 누르는 동안 범위·놓으면 착탄 / 저격: 최대 1.8초 차징, 이동 제한, 범위·피해 증가·자동 발사 | 5초 공속 증가·평타 2연사 |
| 전사 | 120도 검격 | 원형베기: 0.5초 준비·360도 / 연속베기: 4초 내 3회·범위 증가 / 엑스칼리버: 최대 1.8초 차징·범위·피해 증가 | 0.7초 전방 패링, 적 탄막 피해 50%로 반사 |
| 힐러 | 궁수보다 느린 미사일 | 힐링 존: 5초·초당 아군 최대 HP 20%·보스 피해 / 디버프 해제: 자신·3유닛 아군 / 심판: 키를 누르는 동안 레이저·최대 5초·이동 제한 | 3유닛 내 사망 아군 하나, HP 70%·3초 무적 |

화살 비는 사거리 6, 반경 1.3×0.45의 타원에 한 번 피해를 준다. 오지마는 3유닛 범위, 2유닛 넉백이다. 저격은 피해 25→80, 사거리 8→15, 충돌 반경 0.09→0.32다. 힐링 존은 반경 2에서 1초 간격으로 총 5회 처리하며 일반 적에게는 피해를 주지 않는다. 아군 부활 시 사망 카운트다운·시체 표시·충돌 비활성화를 해제한다.

## 다른 담당자 연결

### 몬스터·보스

- `Health.Configure(Faction.Enemy, maxHP, ...)` 및 Collider2D로 피해를 받는다. 자식/중복 콜라이더에도 같은 범위 공격은 한 번만 적용한다.
- 보스는 `BossController`가 붙어 있으면 식별된다. 패턴/페이즈 전환 시작에 `boss.PatternLocked = true`, 종료에 `false`를 설정한다. 이 상태에서는 오지마 넉백만 막고 피해는 적용한다. 현재 임시 보스의 탄막 시전은 0.6초간 자동 잠금된다.
- 현재 보스가 죽으면 보스전 종료를 자동 감지한다. 파티 전멸·시간 초과 등은 전투 담당자가 `BossEncounter.Complete()`를 호출한다. 새 전투는 `BossEncounter.Begin()`이다. 자동 파티 전멸 판정은 전투 담당자에게 남겼다.
- 디버프 탄막은 생성한 `Projectile.InflictsVulnerability = true`를 설정한다. 피격 후 10초간 받는 피해 2배·주는 피해 1.5배이며 힐러가 해제할 수 있다. 직접 적용은 `CombatStatus.ApplyVulnerability(seconds)`이다.
- 반사 가능한 투사체는 공용 `Projectile`을 사용한다. 패링은 전방 140도에서 충돌 직전에 진영·방향·피해를 바꾼다.

### 아이템·인벤토리

- 드롭 담당자는 `BossSkillBook.Spawn(position)`으로 임시 스킬 북을 만들 수 있다. 플레이어가 F로 획득하고 스킬창의 ‘스킬 북 사용’으로 습득한다. 보스 스킬 습득 후 Shift 장착을 선택한다.
- 정식 인벤토리에서는 아이템 획득 시 `loadout.AddBossSkillBook()`, 사용 시 `loadout.UseBossSkillBook()`을 호출한다. 성공 반환 때만 아이템을 소비하도록 연결한다. 이 프로토타입의 내부 스킬 북 개수와 정식 인벤토리 개수를 동시에 별도로 소비하지 않도록 최종 보관 주체를 통합해야 한다.
- 보스 스킬은 Camera.main 화면 안의 살아 있는 모든 Enemy를 한 번씩 공격한다. 보스·레어 몬스터도 포함한다.

### 플레이어·부활

- 플레이어 체력은 `Health`, 사망 이벤트는 `Health.Died`다. 플레이어는 죽어도 GameObject를 파괴하지 않으며 물리·충돌·행동을 즉시 멈춘다.
- 아군은 `Faction.Player`의 살아 있는 GameObject에 `Health`가 있어야 한다. 부활 대상은 사망한 `Health`이며 시체 GameObject를 남겨야 한다.
- `Health.Heal(amount)`는 죽은 대상을 회복시키지 않는다. `Health.Revive(.7f, 3f)`만 사망을 해제하며 일반 공격의 피해 무적 시간도 검사한다.
- 보스전에서는 보스 처치/Complete 후 마을로 귀환하고, 그 외 사망에서는 게임 시간 10초 뒤 귀환한다. 부활하면 예약 귀환이 취소된다.
- `AcceptLocalInput = false`, `SetAim(direction)`, `PlayerSkills.BeginSkill/ReleaseSkill`로 외부 입력을 연결할 수 있지만 아직 네트워크 권한 처리는 없다.

## 에셋 교체

궁수 이동·회피·평타·세 일반 스킬은 전달받은 원본 이미지를 사용한다. 전사·힐러는 임시 도형이다. `Resources/Characters/Warrior`, `Healer`에 Sprite를 넣으면 기본 캐릭터 이미지를 교체한다. 애니메이션 시트가 오면 프레임·피벗을 확인해 애니메이터와 개별 스킬 연출에 연결한다. 판정과 쿨타임은 `PlayerSkills`에 있어 이펙트 교체와 분리돼 있다.

## 검증

Unity 6000.0.60f1에서 `PersistentWorld.Editor.ClassGameplayValidation.RunBatch`를 실행한다. 슬롯 제한·넉백/패턴 보호·화살 비 발동 시점·차징 자동 발사·전사 3연격·패링·치유·디버프 해제·레이저·스킬 북·보스 스킬·사망/부활/10초 귀환을 플레이 모드에서 검사한다. 기존 SkillOneValidation/SkillThreeValidation 명령도 새 통합 검사로 연결된다.

수동 확인: Town 플레이 → ESC 직업 선택 → 스킬 장착 → 필드 전투. 에디터 전용 연습 도구에서 부상/사망 아군과 스킬 북을 만들어 힐러·보스 스킬을 확인할 수 있다.
