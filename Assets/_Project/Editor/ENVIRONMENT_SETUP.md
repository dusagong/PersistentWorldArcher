# Environment assets

Install Cainos **Pixel Art Top Down - Basic**, version 1.2.3, from:
https://assetstore.unity.com/packages/2d/environments/pixel-art-top-down-basic-187605

Import its Texture folder at `Assets/Cainos/Pixel Art Top Down - Basic/Texture`.
Keep the supplied PNG metadata (sprite slices, GUIDs and 32 pixels per unit).
Do not overwrite this project's ProjectSettings with the asset's complete-project settings.

Run **Tools > Persistent World > Rebuild Prototype Scenes** to recreate the decorated
Town, Field and BossArena. The existing gameplay and scene portals remain in use.
The player is displayed at 300 pixels per unit to fit the environment.

The Asset Store source textures are excluded from the public repository. Each team
member must acquire/import the free asset through their own Unity account.
