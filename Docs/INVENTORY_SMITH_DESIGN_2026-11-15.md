# 장비·인벤토리 / 대장장이 디자인 적용 — 2026-11-15

## 승인 범위 및 완료 내용

- 사용자가 승인한 인벤토리 v4 / 대장장이 v4 시안 기준. 남색 계열, 기존 좌우 배치와 대장장이 6개 행을 유지한다.
- 창 외곽 금빛 마감, 내부의 차분한 청회색 금속 테두리, 슬롯 안쪽 음영과 가는 하이라이트를 추가했다.
- 아이템 원본 이미지와 캐릭터 이미지는 변경하지 않았다. 타 게임의 이미지·프레임을 가져오지 않고 Unity 자체 도형으로 장식을 그린다.
- 인벤토리 가방 칸 계산식·간격·기준 크기는 유지했다. 장비 영역만 스크롤 대신 남은 높이에 맞춰 6개 슬롯을 배치한다.
- 대장장이는 목록 행 수에 맞춰 창 높이를 정하도록 바꾸고, 마지막 행 뒤 불필요한 공간을 줄였다. 기존 메시지 영역은 유지한다.
- 대장장이도 이미 프로젝트에 포함된 나눔고딕과 기존 UI Toolkit 해상도 배율 기준을 사용한다.
- 제작·강화·장착·해제 처리, 재료·성공률·수치·저장·RPC 및 기존 드래그 로직은 이번 작업에서 수정하지 않았다.

## 미완료 / 사용자 확인

- 사용자의 빠른 완료 지시에 따라 긴 플레이·Windows 빌드 검증은 실행하지 않았다. 실제 게임 화면과 다른 PC에서의 표시도 아직 확인하지 않았다.
- Unity로 돌아가 재컴파일 후 장비·인벤토리와 대장장이를 열어 표시를 확인해야 한다. 배포 exe에 적용하려면 다시 빌드해야 한다.
- 이전에 보고된 드래그 장착·해제 문제와 파티 팝업 여백은 이번 디자인 전용 변경에서 수정하거나 해결됐다고 판정하지 않았다.
- 커밋·푸시는 하지 않았다. 기존 타 작업의 미커밋 변경을 포함해 되돌리거나 정리하지 않았다.
- 작업 라우팅: 별도 위임 없이 현재 담당 모델에서 직접 처리. 이미지 생성은 두 화면을 동시에 요청했다.

## 버튼 글자 가림 수정

- 실제 사용자 화면에서 카테고리·닫기·제작·장착 등 버튼 글자가 장식 배경에 가려지는 문제가 확인됐다.
- `Button` 자체 글자보다 자식 장식이 나중에 그려지는 것이 원인이다. `RpgUiSurface`의 버튼 장식은 내부를 덮지 않고 테두리만 그리도록 수정했다. 버튼 바탕·hover·disabled 색상은 기존 USS가 담당한다.
- 버튼의 text, 클릭 콜백, 제작·강화·장착·서버 처리 코드는 수정하지 않았다.
- 수정 후 새 장식 코드 컴파일 및 diff 공백 검사 통과. 실제 게임 화면에서 글자가 복구됐는지 최종 재확인은 아직 남아 있다.
