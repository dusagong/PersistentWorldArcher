# 온라인 메뉴 디자인 및 장비 드래그앤드롭 · 2026-11-15

## 승인 범위

- 승인된 ESC 메뉴 시안을 실제 온라인 메뉴에 구현한다. 스킬·직업 선택·튜토리얼 내부 화면도 같은 디자인을 사용한다.
- 추가 승인: 온라인 접속 창·파티·초대/탈퇴·우측 상단 조작 안내 및 기본 스타일 안내창에 공통 테마를 적용한다. 기본 메뉴는 금색, 스킬·조작 안내는 청색, 직업·파티는 녹색으로 구분한다.
- 일반 계정에는 기존 서버 저장 안내와 플레이어 코드 복사 기능을 유지한다. 데모 계정에는 삭제 안내를 표시한다.
- 기존 클릭 후 장착·해제를 유지하면서 장비 드래그앤드롭 장착·해제를 추가한다.
- 인벤토리 디자인, 전투 HUD, 직업·스킬·아이템 수치, 서버 저장·게임 규칙은 변경하지 않는다.
- 기존 타인 변경 PNG meta 23개는 별도 보존한다.

## 구현 현황

- 승인 시안에 맞춰 짙은 중앙 패널, 금속 테두리, 확대된 글자·버튼, 음량 설정, 계정별 안내, 닫기 버튼을 구현했다.
- 스킬·직업 선택·튜토리얼도 같은 프레임·버튼·글꼴을 사용한다. 스킬은 청색, 직업·파티는 녹색, 기본 메뉴는 금색 강조를 사용한다.
- 접속·첫 직업 선택·파티·초대/탈퇴·우측 조작 안내와 기본 안내창에 테마를 연결했다. 서버 접속·장착·직업 변경·튜토리얼 진입 조건과 RPC는 유지한다.
- 일반 계정은 서버 저장 안내 및 플레이어 코드 복사, 데모 계정은 로그아웃 시 삭제 안내를 표시한다. 코드 원문은 화면에 노출하지 않는다.
- 낮은 해상도에서는 메뉴 글꼴 배율을 0.85 이상으로 유지하고 화면 여백에 맞춰 창을 제한한다. 메뉴 내부를 스크롤할 수 있고 닫기·뒤로 버튼은 고정한다.
- 장비 드래그는 가방→맞는 장비 부위 장착, 장비→가방 해제를 지원한다. 클릭 선택·기존 장착/해제 버튼도 유지한다. 부위·직업·소유·가방 공간을 확인하고 기존 ApplySelection/TryEquip/TryUnequip 또는 기존 서버 RPC로 전달한다.
- 드래그 그림자, 대상 강조, 잘못된 대상 표시, 창 닫기·프로필 갱신·포인터 취소·포커스 상실 시 정리를 추가했다. 가방 칸 재정렬 기능은 추가하지 않았다.
- 이 문서는 과거 완료 현황 및 Cainos 패키지 기록과 분리한 오늘의 새 기록이다.

## 검증 결과와 중단 범위

- Unity 6000.0.60f1에서 C# 컴파일 및 Windows 개발 빌드가 두 번 성공했다. 두 번째 빌드에는 포커스 상실 시 드래그 취소 코드가 포함된다.
- 9종 해상도 × 5가지 창 크기 = 45개 창 영역/최소 배율 검사 통과. 이는 계산 검증이며 9종 해상도의 실제 렌더링·다른 PC 검증이 아니다.
- 검증용 Windows Player를 숨김으로 실행했으나 IMGUI Repaint가 관측되지 않아 실제 화면·입력 검사가 시작 단계에서 종료됐다. 이를 제품 UI 오류로 확인한 것은 아니며, 실제 클릭·드래그 검증 통과로도 간주하지 않는다.
- 사용자가 긴 반복 검증을 중단하라고 지시하여 추가 실행 검증은 중단했다. 실행 중인 사용자 Unity를 조작하지 않았다.
- 마지막 글꼴 동봉 및 Resources.Load 연결은 위 빌드 이후 반영했다. 글꼴이 동봉된 최종 Windows 재빌드 및 실제 화면 검수는 아직 하지 않았다.
- `git diff --check` 확인. 기존 변경 PNG meta 23개는 작업 전 해시와 동일하다.
- 결과 및 검증 전용 코드는 `Library/Validation/EscMenuDrag-20261115/`에 보관한다. 테스트 드라이버는 원본 Assets에 넣지 않았다.

- 다른 PC에서의 실제 표시, 9종 해상도 렌더링, 실제 온라인 장비 RPC 왕복 검증은 미완료다. 모든 컴퓨터 정상 표시를 확정하지 않는다.
- 커밋·푸시는 요청받지 않아 수행하지 않았다.

## 사용자 화면 피드백 반영

- 고정 45px 안내 상자를 텍스트의 실제 줄 높이 + 여백으로 변경했다. F 안내도 같은 방식으로 높이를 계산해 줄바꿈 시 잘리지 않도록 수정했다.
- 보스 경고·사망 안내도 같은 높이 계산을 사용한다. 보스 HP는 제목과 게이지 영역을 분리했다.
- 닉네임은 큰 box 스타일을 상속하지 않고 여백 없는 label 스타일로 분리했다. 이름이 가려지던 패딩과 빈 검은 박스를 제거했다.
- 캐릭터 위 파티 HP는 60×4 기준의 얇은 테두리 게이지와 별도 수치로 구분했다. 파티 창의 형광 초록 막대는 차분한 녹색 게이지로 바꾸고 행 높이를 맞췄다.
- 메뉴 X는 우상단 안쪽의 32×32 전용 버튼으로 만들었다. 글꼴의 × 문자를 사용하는 대신 가운데에 선을 그려 크기·정렬을 고정했다.
- 인벤토리는 청남색을 유지하고 외곽선, 헤더 구분선, 슬롯의 밝고 어두운 테두리, 카테고리 탭, 상세 설명 영역을 다듬었다. 장비 슬롯 기준 크기는 유지했다.
- 세트 효과는 장비 스크롤 밖에 두어 장비 그림을 스크롤해도 항상 보이도록 했다. 인벤토리도 동봉 글꼴을 사용하며 공유 글꼴 에셋을 창 종료 시 파괴하지 않도록 구분했다.
- 이 추가 수정 후 Unity 실행·빌드 테스트는 사용자의 지시에 따라 실행하지 않았다. 기능 동작을 검증 완료했다고 주장하지 않는다.
- 추가 변경 파일: `InventoryScreen.uxml`. 나머지는 위에 기재한 관련 UI 파일 내부 수정이다. 새로운 게임 기능·서버 규칙 변경은 없다.
