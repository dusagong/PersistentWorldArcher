# 2026-11-03 HUD 위치 조정

이 문서는 11월 3일 추가 승인된 배치 변경만 기록한다. 이전 HUD·MP 구현과 검증은 `UI_HUD_PLAN_2026-11-02.md`에 보존한다.

## 승인 범위

- HP·MP는 기존 스킬 줄이 있던 하단 중앙으로 이동한다.
- 최신 승인: **“텍스트까지 포함시켜서 hp 윗단~mp 아랫단의 중간배치로 스킬”**. HP 라벨 영역 상단부터 MP 게이지 하단까지의 중간 높이에 실제 스킬 아이콘 중심을 맞춘다. 아이콘 아래 효과 공간은 아이콘 중심 계산에서 제외한다.
- 최신 추가 요청: **“둘다 … 너무높이 … 다시 아까전처럼 조금 내리기”**. 중앙 정렬 관계와 효과의 아래쪽 표시는 유지하고 HP·MP와 스킬 전체를 함께 이전 하단 높이로 내린다.
- 기존 아이콘·바 크기, 색상, 단축키, 효과 표시, 쿨타임, HP·MP 기능과 게임 수치는 유지한다.
- 인벤토리·장비·아이템 관련 코드는 수정하지 않는다.

## 구현

- `CombatHud.uxml`: HP·MP를 별도 묶음으로 분리했다.
- `CombatHud.uss`: 스킬 줄의 상대 하단 위치 -12.5는 유지하고 패널 하단 여백만 46→16으로 되돌렸다. 두 영역이 함께 30 기준 단위 내려간다(1920×1080에서는 45px). 실제 아이콘 중심은 HP 라벨 상단~MP 게이지 하단의 중간 높이를 유지한다. 효과 표시는 아이콘 아래에 남으며 화면 하단에도 3.5 기준 단위의 여백을 확보한다.
- `CombatHud.cs`: HP·MP를 화면 중앙에, 스킬을 우측 여백 16 기준 단위에 배치한다. 기존 1~1.5 배율과 같은 해상도에서 일관된 배치를 유지한다.
- 800×600에서는 중앙 240px 바와 우측 328px 스킬 줄이 겹치므로 아이콘을 축소하지 않고 스킬만 3개+2개로 배치한다. 1024×768 이상인 기존 검증 대상에서는 한 줄이다. 각 아이콘은 기준 56×56, 가로 간격 12, 그림 영역 50×50 그대로다.
- 극단적으로 좁은 창에서는 화면 내부에 두 영역이 들어가도록 전체 배율을 제한한다. 안내 표시나 효과 종료로 HUD가 움직이지 않는다.
- 기존 차징·F 상호작용·대화 안내 및 툴팁은 분리된 HUD 영역 위에서 계속 겹치지 않게 배치한다.

## 진행 및 검증

- 최초 `checks=1235`는 컨테이너 하단 정렬, 두 번째 `checks=1243`은 MP 바 하단 정렬, 세 번째 `checks=1246`은 HP 게이지 상단 정렬 검사였다. 중앙 정렬은 별도 실행(`split-hud-4.log`)에서 통과했고, 최신 하단 복귀 배치도 `split-hud-5.log`에서 `SPLIT_HUD_OK checks=1246`으로 통과했다. 각 해상도의 중앙 정렬 검증 조건은 `actual icon center matches HP label top through MP gauge bottom midpoint`다. 두 영역이 기존 하단 위치로 함께 이동한 것과 효과 표시의 화면 내부 배치도 확인했다.
- 해상도: 800×600, 1024×768, 1280×480, 1280×720, 1366×768, 1920×1080, 2560×1080, 2560×1440, 3840×2160.
- 검증 기준은 중앙 HP·MP, 우측 스킬 여백, HP 라벨 상단~MP 게이지 하단의 중간 높이와 실제 아이콘 중심의 일치, 효과 표시의 화면 내 배치, 양쪽 영역 비겹침, 56px 기준 아이콘·240×8 바 유지와 실제 빨강/파랑 픽셀이다. 800×600의 두 줄 배치는 기존 정책대로 마지막 줄 아이콘의 중심을 맞춘다. 같은 해상도의 reference/fallback DPI 96/144/192 독립성도 검사한다.
- 안내 8가지 조합×9종 해상도에서 HUD 고정, 차징·F·대화·툴팁의 비겹침을 검사했다. 기존 직업 아이콘 갱신, 장착 제한, 쿨타임/효과 구분, MP 소모·즉시 초당 2 회복, 사망/메뉴에서의 기존 동작도 통과했다.
- 최신 하단 복귀 렌더의 1920×1080 화면과 1280×720 효과 활성 화면을 직접 열어 전체 HP·MP 영역과 아이콘 중심 정렬, 효과 표시의 잘림 없음을 확인했다. 확인용 파일은 [화면 보기](Previews/CombatHudSplit-20261103/open-preview.html), 결과와 검사 목록은 `Library/Validation/SplitHudResults/`다. PNG는 최신 하단 복귀 수정본으로 교체했다. 화면 보기의 배경은 격리 검증용 단색이고 영문 안내 상자는 실제 안내가 사용하는 영역의 검증 표시다.
- 실제 다른 컴퓨터·OS 배율 변경·Windows Player 빌드·원본 Town/Field 통합 플레이 검증은 하지 않았다.
- 이번 검증 코드는 `Library/Validation/SplitHudProbe.cs`에만 보관하며 실제 런타임에 추가하지 않는다.
- 다른 작업의 Effects PNG meta 6개, 원본 PDF, 이전 레퍼런스·시안 폴더는 수정하지 않는다.
- 사용자 요청에 따라 이번 배치 변경·이 문서·최신 확인 화면을 `HUD 배치 조정` 커밋으로 `cy`에 공유한다. `main`, 기존 Effects meta 6개, PDF, 이전 시안·레퍼런스는 공유 대상에 포함하지 않는다. 앞선 `HUD·MP 개선` 커밋과 구분한다.
