## 완료 내용

- 사용자 확인 증상: 장비를 누르고 이동해도 아이콘이 따라오지 않음.
- Unity 6에서 버튼이 포인터를 캡처하면 상위 요소의 입력 콜백을 거치지 않는다. 기존 루트 입력 연결을 유지하면서 장비 버튼에도 이동·놓기·취소 콜백을 직접 연결했다. 드래그 시작 후에는 기존 루트 캡처와 드롭 처리를 사용한다.
- 단순 클릭은 기존 버튼 콜백으로 전달한다. 장착·해제, 부위·직업·가방 용량 검사, RPC와 저장 코드는 변경하지 않았다. 무기 포함 모든 장비에 같은 연결을 적용한다.
- 스킬·포션·인벤토리 툴팁은 고정 높이 대신 실제 텍스트 측정값, 줄바꿈, 패딩·테두리를 합산해 너비·높이를 정한다. 표시 위치도 계산된 크기로 화면 안에 보정한다.
- 사용자 추가 요청에 따라 시작 화면에 남던 '로그아웃했습니다' 문구를 비웠다. 접속 진행·오류 안내와 로그아웃 기능은 유지한다.
- 새 계정 생성 시 새 무작위 코드 발급 및 서버 중복 검사 방식은 변경하지 않았다.
