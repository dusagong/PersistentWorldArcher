사망 표시 시안 v1 (2026-11-05)
제작: imagegen 기본 도구. 게임에 미반영한 정적 디자인 시안입니다.

제작 프롬프트 요약:
현재 궁수 에셋의 픽셀풍과 비율을 참고하여 모든 직업에 공통으로 사용할 회색 비석과 작은 흰색 유령을 디자인한다.
비석에는 마름모 음각, 절제된 균열과 낮은 받침을 둔다. 유령은 작은 눈, 처진 입, 짧은 팔과 휘어진 꼬리를 가지며 비석 바로 위에 뜬다.
짙은 초록색 배경에 같은 디자인의 확대 모습과 작은 배치 예시를 나란히 표시한다.
기존 HUD, 메뉴, 캐릭터, 시스템은 시안에 추가하거나 변경하지 않는다.
