# 제작 화면과 무기 강화 미리보기

**제작비 정정:** 기존 대장장이 캡처는 정정 전 화면이며 현재 제작비의 기준이 아니다. 현재 모든 방어구는 재료 1만 5개로 제작한다. 승인된 아이콘 후광 외형은 유지한다.

- [제작·강화 화면](BlacksmithOwnership.png): 장비의 보유 여부와 재료 보유량/필요량을 표시한 실제 UI 캡처.
- [강화 이펙트 GIF](WeaponUpgradeEffects.gif): 실제 Unity Projectile과 WeaponUpgradeVisuals로 촬영한 +1/+2/+3 비교. +1은 흰빛의 짧은 잔상, +2는 푸른빛의 중간 잔상, +3은 금빛의 긴 잔상이다.
- [강화 이펙트 정지 화면](WeaponUpgradeEffects.png): 각 행에 단계 번호를 표시했다.

장비 PNG와 캐릭터 원화를 편집한 이미지가 아니다. 현재 플레이 가능한 궁수 발사체의 색상·잔상 효과이며 전사·힐러의 실제 공격 컨트롤러 연결까지 완료했다고 의미하지 않는다. 미리보기는 별도 프로젝트 복사본에서 촬영한 사용자 확인용 문서 자료다. 검증 코드와 임시 저장 파일은 이 프로젝트에 추가하지 않는다.
## 승인된 강화 아이콘 후광

사용자가 비교 화면을 확인하고 승인한 후광이다. 기본은 후광 없음, +1은 흰빛, +2는 푸른빛, +3은 금빛이다. 양손검·활·마도서에 같은 규칙을 적용하며 원본 PNG는 변경하지 않았다.
