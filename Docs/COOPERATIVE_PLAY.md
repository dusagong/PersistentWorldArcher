# 실제 게임 협동 플레이

`Assets/_Project/Networking/NetworkGame.unity`가 협동 시작 씬이다. 원본 Town·Field·BossArena에 두 번째 필드와 연습장을 더해 한 서버의 구역으로 구성한다. 원본 씬 또는 `CooperativeMapLayouts`를 편집한 뒤 `Tools > Persistent World > Multiplayer > Prepare Cooperative World`로 다시 생성한다. 생성된 협동 씬을 직접 편집하지 않는다. 빌드 PC에 Cainos 패키지를 가져온다. 필드·보스 맵은 패키지의 재질, 셰이더와 Grass Pavement 타일을 사용한다.

## 실행

1. Unity `6000.0.60f1`에서 `Tools > Persistent World > Multiplayer > Build Cooperative Windows Client` 실행.
2. `Builds/CooperativeWindows/PwaCoop.exe` 실행 → 서버 주소·팀 참가 코드·닉네임 입력 → 직업 사진을 선택해 새 플레이어로 시작하거나 데모 플레이. 기존 캐릭터는 개인 플레이어 코드로 복구한다.
3. WASD 이동, 마우스 조준, 우클릭 평타, 좌클릭 특수, Q/E 일반 스킬, Shift 보스 스킬, Space 회피, 1/2 포션, F 상호작용, K 스킬, I 인벤토리, ESC 메뉴. ESC에 튜토리얼·직업 변경·로그아웃·음량 설정이 있다.

현재 피드백 반영 빌드는 서버와 클라이언트 모두 **프로토콜 6**을 사용한다. Railway를 새 서버로 배포할 때 팀원 클라이언트도 함께 교체한다.

## 파티와 보스

- 캐릭터 우클릭 → 파티 초대. 상대 HP 창 위에 수락/거절 버튼이 30초간 표시된다.
- 초대자는 파티가 없으면 1인 파티가 생긴다. 같은 맵에서만 초대하며 이미 소속된 대상은 초대할 수 없다. 정원은 4명이다.
- 왼쪽 상단에 파티 명단·HP·파티장이 표시된다. 파티 창 우클릭 → 탈퇴. 파티장이 나가면 남은 멤버에게 넘어간다.
- 혼자 보스전에 가려면 먼저 `1인 파티 만들기`를 누른다. 입구에서 자동으로 파티를 만들지 않는다.
- 파티원 전원이 같은 필드(Field 또는 Field2)에 살아 있을 때 파티장이 보스 입구에서 F를 누르면 함께 입장한다. 다른 파티가 사용 중이면 거부한다.
- 보스 룸에서는 파티를 편성할 수 없다. 보스 룸에서 탈퇴하면 마을로 돌아간다. 마지막 멤버가 나가거나 접속을 끊으면 룸을 초기화한다.
- 일반 지역 사망은 10초 뒤 마을 귀환. 보스전 사망자는 부활 또는 전투 종료까지 대기하고 전멸하면 마을로 귀환한다.
- 스킬 장착·해제 및 직업 변경은 마을에서만 가능하다. 서버에서도 검사한다.
- 전사 패링 반사탄은 원래 피해의 **500%(5배)**다. 원래 20이면 반사 100이며 대상의 방어·감소 효과는 별도 적용한다.

## 구현 범위와 검증

서버가 이동·스킬·피해·회복·사망·몬스터/보스 AI·파티/룸 상태를 계산한다. 클라이언트는 입력을 보내고 10Hz 시각 상태와 HP를 받는다. 화면 프레임마다 캐릭터와 카메라 위치를 보간한다. 원본 스프라이트는 클라이언트 빌드에도 포함한다.

새 플레이어의 개인 코드는 클라이언트가 생성하고 기억한다. ESC 메뉴의 ‘내 플레이어 코드 복사’로 보관한다. 다른 PC에서는 같은 서버에 개인 코드를 입력해 ‘코드로 로그인’을 선택한다. 코드를 가진 사람이 해당 캐릭터에 접속할 수 있으므로 본인만 보관한다. 팀 참가 코드와 개인 복구 코드는 별개다. 한 캐릭터로 동시에 접속할 수 없다. 데모는 영구 저장하지 않으며 명시적으로 로그아웃하면 진행을 삭제한다.

직업별 장비와 가방, 강화 단계, 스킬과 보스 스킬 북은 서버에 저장된다. 재접속 위치는 마을이다. 서버는 접속 종료 시 기존 파티 자리를 정리한다. 필드 드롭은 가까이 가면 줍고, 몬스터는 20초 뒤 다시 나온다. 마을 대장장이 옆에서 F를 누르면 제작·강화 창이 열린다. 인벤토리에서 물약을 1·2번에 장착한다. 전투 중 각 키를 누르면 최대 30 회복하며 두 슬롯에 독립적인 10초 쿨타임이 있다. 보스를 처치하면 보스방에 남은 파티원에게 캐릭터당 보스 스킬 북 한 권을 지급한다.

```powershell
# Windows 협동 빌드 후 실제 RPC 4인 검사
./Deploy/Test-Party.ps1
# 두 클라이언트 이동 및 잘못된 코드 거부
./Deploy/Test-Network.ps1
# Linux 빌드 준비 및 컨테이너로 같은 4인 검사
./Deploy/Railway/Prepare-Deployment.ps1
docker build -t pwa-cooperative-test:local Builds/Railway
./Deploy/Test-Party.ps1 -LinuxServer
```

파티 모델 `PersistentWorld.Editor.PartyValidation.Run`: 33개 검사.
4인 통합 **71개**: 초대 거절/수락, 정원, 탈퇴, 개인 상태, 필드 스킬 교체 거부, 무파티/비파티장/다른 파티 입장 제한, HP 전송, 룸 반환, 실제 5배 반사 피해, 전사 HP·공격 배율·패링 시간, 실제 필드·보스 AI, 사망 대기·이미지·부활·10초 귀환·전멸, 재료 3배/포션 유지, 포션 슬롯·쿨타임, 제작·장착·강화·저장 복원, 두 번째 필드·힐러 연습 효과와 클라이언트 전송·초기화·정리를 검사한다. 계정 생성/복구/데모 수명은 `Test-Accounts.ps1`로 별도 확인한다.
로그는 `Library/Validation/Party-*`에 저장한다. `-Capture` 이미지는 카메라로 렌더링한 월드 화면이며 GUI 캡처가 아니다.
`-pwa-party-validation`은 로컬 검증 전용이며 운영 서버에 사용하지 않는다. 같은 PC의 다중 프로세스 검사이므로 실제 4명 인터넷 플레이를 추가 확인한다.
