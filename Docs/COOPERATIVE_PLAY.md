# 실제 게임 협동 플레이

`Assets/_Project/Networking/NetworkGame.unity`가 협동 시작 씬이다. 원본 Town·Field·BossArena를 한 서버의 구역으로 가져온다. 원본 씬을 편집한 뒤 `Tools > Persistent World > Multiplayer > Prepare Cooperative World`로 다시 생성한다. 생성된 협동 씬을 직접 편집하지 않는다. 빌드 PC에 Cainos 패키지를 가져온다. 새 필드·보스 맵은 패키지의 재질, 셰이더와 Grass Pavement 타일을 사용한다.

## 실행

1. Unity `6000.0.60f1`에서 `Tools > Persistent World > Multiplayer > Build Cooperative Windows Client` 실행.
2. `Builds/CooperativeWindows/PwaCoop.exe` 실행 → 이름·서버 주소·참가 코드 입력.
3. WASD 이동, 마우스 조준, 우클릭 평타, 좌클릭 특수, Q/E 일반 스킬, Shift 보스 스킬, Space 회피, F 상호작용, ESC 장비·인벤토리, 스킬, 직업 선택.

마을 개편 빌드는 서버와 클라이언트 모두 **프로토콜 5**를 사용한다. Railway를 새 서버로 배포할 때 팀원 클라이언트도 함께 교체한다.

## 파티와 보스

- 캐릭터 우클릭 → 파티 초대. 상대 HP 창 위에 수락/거절 버튼이 30초간 표시된다.
- 초대자는 파티가 없으면 1인 파티가 생긴다. 같은 맵에서만 초대하며 이미 소속된 대상은 초대할 수 없다. 정원은 4명이다.
- 왼쪽 상단에 파티 명단·HP·파티장이 표시된다. 파티 창 우클릭 → 탈퇴. 파티장이 나가면 남은 멤버에게 넘어간다.
- 혼자 보스전에 가려면 먼저 `1인 파티 만들기`를 누른다. 입구에서 자동으로 파티를 만들지 않는다.
- 파티원 전원이 필드에 살아 있을 때 파티장이 보스 입구에서 F를 누르면 함께 입장한다. 다른 파티가 사용 중이면 거부한다.
- 보스 룸에서는 파티를 편성할 수 없다. 보스 룸에서 탈퇴하면 마을로 돌아간다. 마지막 멤버가 나가거나 접속을 끊으면 룸을 초기화한다.
- 일반 지역 사망은 10초 뒤 마을 귀환. 보스전 사망자는 부활 또는 전투 종료까지 대기하고 전멸하면 마을로 귀환한다.
- 스킬 장착·해제 및 직업 변경은 마을에서만 가능하다. 서버에서도 검사한다.
- 전사 패링 반사탄은 원래 피해의 **500%(5배)**다. 원래 20이면 반사 100이며 대상의 방어·감소 효과는 별도 적용한다.

## 구현 범위와 검증

서버가 이동·스킬·피해·회복·사망·몬스터/보스 AI·파티/룸 상태를 계산한다. 클라이언트는 입력을 보내고 10Hz 시각 상태와 HP를 받는다. 화면 프레임마다 캐릭터와 카메라 위치를 보간한다. 원본 스프라이트는 클라이언트 빌드에도 포함한다.

첫 접속에는 캐릭터 복구 키를 비워둔다. 클라이언트가 서버별 키를 만들고 기억한다. 다른 PC에서는 접속 화면에서 복사한 키를 붙여넣는다. 키를 가진 사람이 해당 캐릭터에 접속할 수 있으므로 본인만 보관한다. 한 캐릭터로 동시에 접속할 수 없다.

직업별 장비와 가방, 강화 단계, 스킬과 보스 스킬 북은 서버에 저장된다. 재접속 위치는 마을이다. 서버는 접속 종료 시 기존 파티 자리를 정리한다. 필드 드롭은 가까이 가면 줍고, 몬스터는 20초 뒤 다시 나온다. 마을 대장장이 옆에서 F를 누르면 제작·강화 창이 열린다. 인벤토리에서 체력·마나 물약을 사용하면 각각 최대 30을 회복한다. 보스를 처치하면 보스방에 남은 파티원에게 캐릭터당 보스 스킬 북 한 권을 지급한다.

```powershell
# Windows 협동 빌드 후 실제 RPC 4인 검사
./Deploy/Test-Party.ps1
# 두 클라이언트 이동 및 잘못된 코드 거부
./Deploy/Test-Network.ps1
# Linux 빌드 준비 및 컨테이너로 같은 4인 검사
./Deploy/Railway/Prepare-Deployment.ps1
docker build -t pwa-cooperative-test:local Builds/Railway
./Deploy/Test-Party.ps1 -LinuxServer
```

파티 모델 `PersistentWorld.Editor.PartyValidation.Run`: 33개 검사.
4인 통합: 초대 거절/수락, 정원, 탈퇴, 개인 상태, 필드 스킬 교체 거부, 무파티/비파티장/다른 파티 입장 제한, HP 전송, 룸 반환, 실제 5배 반사 피해, 실제 필드·보스 AI, 보스 사망 대기·사망 이미지 전송·부활·필드 사망 후 귀환·전멸 시 룸 반환, 종료 정리: 50개 검사. 서버 드롭·리스폰, 제작·장착·강화, 보스 보상, 실제 재접속 뒤 복원까지 확인한다.
로그는 `Library/Validation/Party-*`에 저장한다. `-Capture` 이미지는 카메라로 렌더링한 월드 화면이며 GUI 캡처가 아니다.
`-pwa-party-validation`은 로컬 검증 전용이며 운영 서버에 사용하지 않는다. 같은 PC의 다중 프로세스 검사이므로 실제 4명 인터넷 플레이를 추가 확인한다.
