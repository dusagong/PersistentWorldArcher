# 요청별 반영 및 검수 기록 — 2026-11-13

이번 범위는 플레이·UI·밸런스·맵 피드백 전체와 앞서 요청한 온라인 HUD·포션·파티·사망 기능이다. 보스 **신규 패턴 다양화**는 사용자 요청대로 제외한다. 기존 패턴과 공격 경고 표시의 수정은 유지한다.

`구현`은 배포 후보 소스에 포함됐다는 뜻이다. 실제 플레이 확인과 원격 테스트 결과는 아래 검수·배포 기록에서 별도로 확인한다.

## 플레이

- [x] BGM 추가 — 마을/연습장과 전투 지역의 서로 다른 오리지널 테마 2곡. WAV를 빌드에 포함하고 반복 재생한다.
- [x] 공격·타격·피격 등 효과음 — 활·검·마법 평타, 타격, 피격, 스킬, 포션, 사망의 8종. ESC 메뉴에서 BGM/효과음 음량을 각각 조절한다.
- [x] 메인 화면 조정 — 중앙 로그인 패널, 닉네임·팀 참가 코드·개인 플레이어 코드, 새 플레이어/복구/데모/종료 버튼.
- [x] 플레이어 정보 저장 및 로그인 — 선택한 **플레이어 코드 방식** 적용. 직업별 장비·인벤토리·강화·스킬·포션 장착을 서버에 저장하고 코드로 복구한다. ID/PW 방식은 선택하지 않았다.
- [x] 일회성 데모 계정 — 디스크 저장 없음. 명시적 로그아웃 시 삭제. 통신 장애의 자동 재접속만 90초 동안 메모리에서 복구한다.
- [x] 첫 플레이 직업 선택 — 궁수·전사·힐러 사진과 클래스 이름을 표시하고 사진/선택 버튼으로 시작한다.
- [x] ESC 조작 튜토리얼 — 안내 페이지와 실제로 움직이고 공격하는 별도 연습장. 연습 중 플레이어 피해와 아이템 소비를 차단한다.
- [x] 힐러 연습 상황 — HP 30/100 회복 대상, 실제 취약·감속 상태인 정화 대상, HP 0인 부활 대상을 제공한다. 실제 효과가 발생하면 완료로 표시한다.
- [x] 연습 재시도 — 자신의 HP/MP/쿨타임·연습 대상을 초기화한다. 참가자별 연습 위치를 분리하고 퇴장/접속 종료 시 대상을 정리한다. 재접속으로 클라이언트 ID가 바뀌어도 빈 연습 자리를 할당한다.
- [x] 몬스터 피격 표시 — 피해 사건을 서버에서 전송하고 빨간색 50% 점멸을 표시한다.
- [x] 몬스터 피해 숫자 — 서버가 계산한 실제 피해량을 몬스터 위에 표시한다. 같은 사건을 반복 표시하지 않는다.
- [x] 이동 끊김 개선 — 시간표가 있는 위치 기록을 보간하고 순간이동 시 기록을 초기화한다. 신뢰 전송량을 무리하게 늘리는 대신 화면을 매 프레임 갱신한다.
- [x] 그림자 지연 수정 — 캐릭터가 실제 그려지는 좌표와 같은 좌표에서 그림자를 갱신한다. 머리 위 이름도 같은 좌표를 사용한다.
- [x] 시작 화면 게임 종료 버튼.
- [x] main과 다른 경고 범위 표시 수정 — 슬라임 원형 경고, 보스 원·테두리 사각형을 원래 스프라이트로 재현하고 Sliced 크기를 동기화한다.
