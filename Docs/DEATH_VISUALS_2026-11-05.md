# 2026-11-05 사망 표시 작업

## 승인 범위

- 승인된 비석 + 유령 시안을 게임의 사망 표시에 적용한다.
- 파티 시스템과 전멸 판정은 이번 작업에서 제외한다.
- 기존 귀환, 보스전 대기, 힐러 부활, HP/MP, 스킬 동작과 수치는 유지한다.
- 이전에 완료한 HUD/인벤토리 현황과 분리해 이 문서에 기록한다.

## 적용 내용

- `PlayerDeathVisual`을 추가했다. 사망 위치의 발밑에 비석을 표시하고, 그 위에 작은 유령이 천천히 떠 있도록 했다.
- 기존 캐릭터 스프라이트는 사망 중 숨기며, 부활하면 비석과 유령을 제거하고 원래 캐릭터 표시를 복구한다.
- 표시를 플레이어의 자식으로 생성하여 마을 귀환이나 플레이어 제거 시 함께 정리한다.
- 별도 충돌체, 타깃, 부활 판정을 추가하지 않는다. 힐러 부활은 기존 플레이어의 Health를 그대로 사용한다.
- PNG의 투명 여백은 텍스처마다 처음 한 번 계산해 캐싱한다. 표시 크기는 화면 픽셀값이 아닌 월드 단위로 유지한다.
- 기존 `ArcherController`에서는 사망 외형 처리와 부활 시 표시 제거 연결만 변경했다.

## 검증

- 원본 프로젝트와 분리된 Unity 복사본의 Play 모드에서 사망·부활·귀환을 검증한다.
- 세 직업의 즉시 표시/복구, 반복 사망 시 중복 제거, 물리·입력 차단 유지, 사망 중 MP 회복 정지, 쿨타임 유지, 보스전 대기, 실제 힐러 부활, 10초 뒤 실제 Town 씬 귀환을 포함한 55개 검증을 통과했다.
- 실제 렌더링을 확인한 뒤 비석 높이 0.5, 유령 높이 0.32 월드 단위로 축소해 캐릭터에 맞췄다. 최종 크기로 55개 검증을 다시 통과했다.
- 결과: `Library/Validation/DeathVisual-20261105/result.txt`. 화면: `Docs/Previews/DeathVisual-20261105/`의 `Archer-dead.png`, `Warrior-dead.png`, `Healer-dead.png` 및 각 `*-revived.png`.
- 화면은 검증용 씬에서 실제 코드를 실행해 렌더링한 이미지다. Field 씬과 같은 카메라 크기를 사용했으나, 원본 프로젝트에서 직접 플레이하거나 다른 PC에서 확인한 결과는 아니다.
- Unity CLI 연결에 필요한 Pipeline 패키지가 현재 프로젝트에 없어 기존 Unity Editor 배치 실행 방식을 사용한다. 검증 프로세스는 숨김으로 실행한다.
- 기존 미커밋 PNG meta 23개는 별도 변경으로 유지하며, 이번 작업에 포함하거나 수정하지 않는다.
- 위임하지 않음: 승인 범위가 제한된 사망 외형 연결 작업이므로 현재 에이전트가 직접 수행한다.
