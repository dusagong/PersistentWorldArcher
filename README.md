# Persistent World Archer

Unity 2D 협력 RPG의 공용 개발 기반이다. 궁수·전사·힐러를 선택해 마을, 필드 전투, 보스전을 플레이하는 로컬 프로토타입이다. 스킬 동작은 [팀 기획서](https://docs.google.com/document/d/1-IJpkKf11RCMhlBzN7e_wYJQlbsPxWvhcr-qrMAdYfc/edit)를 기준으로 한다. 최종 수치·MP 소모·정식 에셋은 후속 조정 대상이다.

## 고정 환경

- Unity Editor `6000.0.60f1`
- 대상: Windows PC, 키보드와 마우스
- 외부 코드 편집기: VS Code
- 렌더링: Built-in 2D
- 시작 씬: `Assets/_Project/Scenes/Town.unity`

Unity Hub에서 이 폴더를 열면 필요한 씬이 이미 Build Settings에 등록되어 있다. 처음 열 때 Unity가 `Library`와 IDE 파일을 로컬에서 다시 생성한다.

## 현재 플레이 범위

- 마을: 대화 가능한 NPC와 필드 이동 게이트
- 필드: 선택한 직업의 이동·평타·스킬, 일반 몬스터, 보스 방 게이트
- 보스 방: 2페이즈 보스와 필드 복귀 게이트
- 궁수: 전방 90도 넉백, 조준 후 발동하는 화살 비, 차징 저격. 특수는 5초간 공속 증가·평타 2연사.
- 전사: 120도 평타, 0.5초 준비 후 원형베기, 4초 내 3단 연속베기, 차징 엑스칼리버. 특수는 전방 탄막 50% 피해 반사.
- 힐러: 마법 미사일, 5초 힐링 존(초당 최대 HP 20%, 보스 피해), 아군·자신 디버프 해제, 최대 5초 심판 레이저. 특수는 아군 HP 70% 부활·3초 무적.
- ESC 스킬창: 일반 슬롯 Q/E 2개, 보스 슬롯 Shift 1개, 장착·해제·중복 및 직업 제한. 특수 스킬은 직업 고정.
- 보스 스킬: 스킬 북 획득 → 스킬창에서 사용 → Shift 장착 → 화면 내 모든 적 공격.
- 사망: 즉시 행동·물리 정지, 회색 시체 표시. 일반 지역은 10초 후 마을 귀환, 보스전은 종료까지 대기 후 귀환. 힐러 부활 시 귀환 취소.
- 공용 전투: 체력, 진영, 피해, 투사체, 사망 처리
- 플레이어 에셋: 사용자 제공 8프레임 스프라이트 시트, 이동 애니메이션과 좌우 반전
- 배경: Cainos Pixel Art Top Down - Basic 잔디/돌길 타일맵, 나무, 우물, 소품, 보스 제단
- NPC/적/포탈: 단색 임시 도형 유지

배경 에셋 설치 방법은 [ENVIRONMENT_SETUP.md](Assets/_Project/Editor/ENVIRONMENT_SETUP.md)를 참고하세요.
공개 저장소에는 Asset Store 원본 텍스처를 포함하지 않으므로 팀원도 해당 무료 에셋을 받아야 합니다.

## 조작

| 입력 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 조준 |
| 우클릭 | 직업별 평타 (누르고 있으면 반복) |
| 좌클릭 | 직업 고정 특수 스킬 |
| Q / E | 일반 장착 스킬 1 / 2 |
| Space | 이동 방향 회피, 정지 중에는 조준 반대 방향 |
| Shift | 장착한 보스 스킬 |
| F | NPC 대화 또는 게이트 사용 |
| ESC | 스킬 장착·해제 및 마을 직업 선택 |

기본 장착은 각 직업의 스킬1·스킬2다. 스킬3은 ESC → 스킬에서 Q/E 중 한 곳에 교체 장착한다. 차징·범위 스킬은 해당 키를 누르고 있다가 놓아 사용한다. 차징과 레이저 도중에는 이동·회피가 잠긴다. ESC를 열거나 사망하면 진행 중인 시전은 취소된다. 메뉴를 열어도 월드는 정지하지 않는다.

스킬 장착·습득한 보스 스킬·보유 스킬 북·스킬 쿨타임은 플레이 세션 안에서 씬 이동 후 유지된다. 장비·인벤토리·무기 강화·선택 직업은 로컬 파일에 저장하며, 직업 변경 시 각 직업의 장비·가방·강화 상태를 복원한다. 스킬 상태의 게임 종료 후 저장과 서버 동기화는 아직 연결하지 않았다. 전사·힐러는 임시 캐릭터·도형 이펙트를 사용한다.

에디터에서는 ESC → 직업의 연습 도구로 부상/사망 아군과 스킬 북을 생성할 수 있다. 팀 통합 API와 검증 방법은 [CLASS_SKILLS.md](Assets/_Project/Scripts/Player/CLASS_SKILLS.md)를 참고한다.

## 프로젝트 구조

```text
Assets/_Project/
  Editor/       프로토타입 씬 생성 도구
  Scenes/       Town, Field, BossArena
  Scripts/
    Combat/     체력, 피해, 투사체
    Core/       상호작용과 임시 표시
    Player/     공통 입력·이동·사망, 직업 스킬·장착
    World/      적, 보스, NPC, 게이트, 카메라, HUD
```

런타임 코드는 `PersistentWorld.Runtime` 어셈블리로 묶었다. 에디터 도구는 별도 어셈블리이므로 빌드에 포함되지 않는다.

## 팀 작업 규칙

1. `main`은 항상 실행 가능한 상태로 유지한다.
2. 작업 브랜치는 `feature/기능명`, 수정은 `fix/내용` 형식을 사용한다.
3. 한 씬을 여러 명이 동시에 수정하지 않는다. 공용 로직은 프리팹과 스크립트로 분리한다.
4. `.meta` 파일은 반드시 함께 커밋한다.
5. `Library`, `Temp`, `Logs`, IDE 생성 파일과 빌드는 커밋하지 않는다.
6. Pull Request에는 변경 범위, 확인 방법, 영향받는 씬을 적는다.

## 다음 결정 사항

온라인 지속 월드는 아직 구현하지 않았다. 네트워크 패키지와 서버 권한 구조를 팀에서 확정한 뒤 이동, 피해, 몬스터 상태, 리젠과 보상을 서버 권한으로 옮긴다. 장비 수치와 방어 공식은 프로토타입 값이다. 방어구는 기획 원문 표에 따라 재료 1만 5개로 제작하며 강화는 사용자 승인 비용을 따른다.

## cy 인벤토리·장비 작업

- Town 시작 지점 왼쪽 아래에 실행 시 임시 네모 대장장이가 생긴다. 가까이 가서 `F`를 누르면 제작 화면이 열린다.
- 직업 무기는 시작 시 지급·자동 장착한다. 대장장이에서는 방어구 제작과 무기 강화(+1/+2/+3)를 한다. 강화 비용은 각 재료 5/7/10개, 성공률 100%다. 무기를 해제하면 평타·공격 스킬이 막히며 지원 스킬은 사용할 수 있다. 창은 `ESC` 또는 닫기로 닫는다.
- 장비를 가방에 보관하거나 장착하고 있으면 재제작을 막고 보유 여부로 표시한다. 제작·강화 재료는 보유량/필요량으로 보여준다. 장비·소재 이름은 몬스터 명칭 확정 후 변경한다.
- 인벤토리는 40칸이고, 재료·소모품은 칸당 99개를 중첩한다. 장비는 개당 한 칸이며 장착 중인 장비는 가방 칸에서 빠진다.
- 3세트는 일반 몬스터에만 +20%, 5세트는 보스 피격 -20%, 6세트는 보스 공격 +30%다. 레어에는 3세트가 적용되지 않는다.
- 보유 아이템과 장착 상태는 씬을 이동해도 유지되며, 게임 재실행 시 로컬 파일에서 복원한다.
- 드롭 기능 연결 전 제작을 확인하려면 Play 모드에서 `Tools > Persistent World > Items > Give Test Materials (Play Mode)`를 사용한다. 현재 프로필에 테스트 재료를 추가하고 저장하므로 테스트 용도로 사용한다. 게임 실행 시 무료 재료는 자동 지급하지 않는다.
- `ESC → 장비 · 인벤토리`로 통합 창을 연다. 캐릭터 주변 6부위 장비와 오른쪽 40칸 가방, 네 가지 분류 탭, 아래 선택 정보와 장착·해제 버튼을 배치했다. 새 화면은 별도 복사본 Unity에서 배치·장착/해제·직업 제한·가방 부족 처리를 확인했다.
- 별도 아이템 조합은 팀 합의 전까지 보류한다.

`cy` 통합 시 최신 스킬·사망 코드를 보존하면서 ESC 메뉴의 ‘장비 · 인벤토리’ 버튼을 연결했다. 장비 공격력은 세 직업의 공격 스킬에도 반영하며, 세트 효과는 일반·레어·보스를 구분한다. 피해 처리에서 방어력·보스 피격 감소·디버프·부활 무적이 함께 적용된다. 강화 화살의 실제 스프라이트에도 색상과 잔상이 유지된다.

검증 명령 `PersistentWorld.Editor.ClassGameplayValidation.RunBatch`는 기존 스킬·사망 검사에 인벤토리 제작·강화·저장·실제 UI 검사를 추가했다. 배치 검증은 `Library/Validation`의 격리된 저장을 사용하며 개인 저장을 읽거나 수정하지 않는다. 통합 검토 결과는 [Docs/CY_MERGE_REVIEW.md](Docs/CY_MERGE_REVIEW.md)에 정리했다.

팀 연결 API와 저장·검증 방법은 [ITEM_SYSTEM.md](ITEM_SYSTEM.md), 전체 계획은 [CHANYOUNG_PLAN.md](CHANYOUNG_PLAN.md)를 참고한다. Town 씬 파일은 수정하지 않았고 씬 재생성 메뉴도 실행하지 않았다.

씬을 다시 생성해야 할 때 Unity 메뉴에서 `Tools > Persistent World > Rebuild Prototype Scenes`를 실행한다. 이 명령은 세 프로토타입 씬을 덮어쓰므로 씬을 직접 편집한 뒤에는 실행하지 않는다.

## 궁수 평타 애니메이션

우클릭마다 캐릭터 앞에 활 4프레임을 한 번 재생하고, 0.18초에 조준 방향으로 화살 한 발을 발사한다. 누르고 있으면 0.45초마다 반복하며, 일석이조 상태에서는 0.27초 간격·화살 2연사가 적용된다. 기본 피해량은 발당 10이다.
